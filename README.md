# 🤖 AI SQL Analyst

An AI-powered SQL Analyst that allows users to upload CSV files and analyze data using natural language.

## ✨ Features

- 📁 Upload CSV files
- 🤖 AI-powered SQL query generation
- 📊 Interactive Dashboard
- 📈 Data visualization
- 🗂 Workspace for uploaded datasets
- 📝 Query history
- ⚡ FastAPI Backend
- ⚛ React + Vite Frontend
- 🐘 PostgreSQL (Neon)
- 🐳 Docker Production Ready
- 🌐 Nginx Reverse Proxy

```bash

```

```bash

```

```bash

```
